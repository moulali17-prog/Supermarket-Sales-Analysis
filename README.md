# Supermarket Sales Analysis Using Python

## Project Overview
This project analyzes supermarket sales data using Python and Data Science techniques. It identifies sales trends, compares product line performance, evaluates branch revenue, and explores customer purchasing patterns.

## Internship Details
- Organization: CODTECH Solutions
- Domain: Data Science
- Project Title: Supermarket Sales Analysis Using Python

## Objectives
- Analyze overall supermarket sales.
- Identify the highest-revenue product lines.
- Compare sales across different branches.
- Analyze customer payment preferences.
- Evaluate customer ratings.
- Analyze sales by day and hour.
- Visualize sales trends using charts.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Google Colab

## Dataset
The project uses the Supermarket Sales dataset containing transaction details, product lines, branches, customer information, payment methods, sales totals, dates, times, and customer ratings.

Dataset Source:
https://www.kaggle.com/datasets/aungpyaeap/supermarket-sales
